# Event template

Copy this folder for each new event and rename it `YYYY-MM-DD_event-name`. One file per question, so you and your assistant always know where an event fact lives.
The steps from first idea to archive, with the prompt for each: `04-knowledge-base/event-lifecycle.md` in the kit.
Optional later: `follow-up.md` (open loops after the event) and `YYYY-MM-DD_whatsapp-summary.md` (what the chapter keeps from the event group; the chat itself stays on your phone).
