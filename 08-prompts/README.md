# 08 · Prompts

Ready-to-use prompts for everyday Chapter Manager work. The other folders hold your files; these prompts put them to work.

## What this is

A small library for the work that comes back every week and every event: following up, onboarding, answering rule questions,
checking the budget, filing mail and WhatsApp, running an event from brief to debrief, keeping the game plan alive, keeping the chapter's memory current, and seeing where your own hours go.
Every prompt says what it reads, which file it produces, and the one check you do yourself.

## Why it matters

The same prompt, used every time, gives you comparable results — and a result that lands in a file stays with the chapter.
That is how a few minutes per task add up to a knowledge base a stand-in or the next officer can continue from.

## What's inside

| File | What it gives you |
|---|---|
| [prompt-library.md](prompt-library.md) | 40 prompts in nine groups: A Events · B Members · C Rules and meetings · D Finance · E Communication · F Memory and handover · G Event lifecycle · H Game plan · I Time by area — and how to share a prompt of your own |

Start with three: **11 Email handoff**, **8 Post-event debrief** and **13 Checkpoint**. Add the others when the need comes up.

## How to use it with your AI

1. **First session:** *"Read 08-prompts/prompt-library.md. Which three prompts would save me the most time this month, given 00-handover/handover.md?"*
2. **Save what works:** copy your favourite prompts, with your own placeholders filled in, into your chapter folder's `08-prompts/` — your assistant prefers them.
3. **Improve them:** when a prompt needed a correction twice, change the saved version, and add a log line saying why.
4. **Share them:** a prompt that works for you may work for other chapters — see "Share a prompt" at the end of [prompt-library.md](prompt-library.md).
