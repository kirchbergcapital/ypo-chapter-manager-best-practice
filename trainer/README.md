# Trainer folder

Purpose: everything a trainer needs to run the Chapter Manager workshop *Operational AI Excellence for Chapter Managers* — the same format for every room, 120 minutes, with a 90-minute version.

> Community format by a YPO member, not an official YPO programme. Participants do not need this folder — they start at [../START-HERE.md](../START-HERE.md).

## The one idea

> Chairs and officers rotate every year; the Chapter Manager stays. AI helps them become — and keep — the memory of the chapter, without more hours.

"Without more hours" is said as a bet, not a promise: the hours come from searching and answering twice — each participant tests it with their own week.

## The workshop in one table

| Min | Block | Participants build |
|---|---|---|
| 0–10 | Opening | — (the wall question: which one burns most today?) |
| 10–20 | Foundation | A lab neighbour, if they want one |
| 20–50 | KNOW | AI project + house rules + folder + a short `chapter-facts.md` that answers one question (Lab A); full interview as homework |
| 50–80 | REACH | One fictional Lakeside mail filed, log line, draft — not sent (Lab B) |
| 80–106 | PERSIST | `handover.md` checkpoint (Lab C), tested by a "new officer" from the next chair ("Chairs rotate"); what stays yours; one-pager for the ExCo |
| 106–115 | Show & outlook | Show in pairs = success test, self-count with dots *running / homework*; 1-minute outlook video |
| 115–120 | Close | Feedback; follow-up through one agreed channel |

## How to use this folder

1. Read [format-guide.md](format-guide.md) end to end, including "Your two roles".
2. Fill your own role-lens placeholders — `[Trainer: own example as chair]`, `[Trainer: own observation as regional officer]` — in your copy. Never invent an example; leave the slot to the kit's pattern line instead.
3. Build your demo set-up from [demo-scripts.md](demo-scripts.md) and do the three labs yourself once.
4. Follow the T-14 / T-7 / T-1 list in [run-it-yourself.md](run-it-yourself.md), and agree the follow-up channel ([follow-up.md](follow-up.md)).
5. Decide which room you are in: a guest in another region, or your own region — the format guide has a section for each.

The participant side of the preparation is in [../00-before-the-workshop/](../00-before-the-workshop/README.md).
