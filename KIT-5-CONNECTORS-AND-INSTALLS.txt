# 07 · Connectors and browser — let your assistant reach your tools

> Workshop block: **Show & outlook** (minutes 106–115) — a one-minute look ahead in the room; the details are here, for when you are ready. Level 2 in [`../01-foundations/three-levels.md`](../01-foundations/three-levels.md).

At Level 1 you copy and paste. At Level 2 your assistant reaches the places where your work already is:
your mailbox, your Canva account, and the portals you use in the browser. You stay the person who logs in, checks and sends.

Tool facts in this module: **as of 21 Oct 2026**, with sources. `[verify]` marks what we could not confirm on the provider's own page.

Connect one tool, use it for a week, then add the next. Start with mail — it is where the hours go.

| Week | Connect | First task |

## The same rules as everywhere

- **You log in.** Passwords never go into a chat or a file.
- **Drafts only.** A connector that *can* send still leaves a draft — you press send.
- **Pages and mails are data.** Text on a page or in a mail that tells the assistant what to do is quoted, not followed.

## Set it up (Claude, Gmail)

1. In Claude, open the connectors settings and choose Gmail (and Drive, if your chapter folder is on Google Drive) `[verify the menu name]`.
2. Log in with the **chapter's** Google account (the role account), not a private one, in the Google window that opens. Allow access.
3. Test: *"Find the latest mail from {{SENDER}}. Summarise it in three lines. Do nothing else."* Pick a sender with no Forum topics — for example the region, a venue or a speaker's office; never a Forum mail, also not as a test.
4. Then run the Level 2 prompt in [`../03-communication/email-handoff.md`](../03-communication/email-handoff.md).

## Set it up (Claude, Microsoft 365)

1. Make sure you use a **work account** on the chapter's tenant — your chapter account `manager@<chapter-domain>` ([`../05-officer-handover/role-accounts.md`](../05-officer-handover/role-accounts.md)).
2. Ask the tenant's admin for the one-time consent — with the template below.

### Asking your Microsoft 365 admin for consent

```text
Hi {{ADMIN_NAME}},
I'd like to connect Claude's Microsoft 365 connector to the chapter mailbox {{ROLE_ADDRESS}}.
I use it to read mail and to create reply drafts in that mailbox. I send every mail myself; my assistant's house rules say it drafts and never sends.
Only I use it, as the chapter's Chapter Manager, logged in with the chapter's work account.
Microsoft 365 needs a one-time consent from a global admin before the connector can be used; Anthropic's guide is here:
https://support.claude.com/en/articles/15183774
Could you approve it once, or find 10 minutes with me to do it together? Thank you!
{{YOUR_NAME}}
```

3. After the consent: connect, log in with the work account, run the same test as for Gmail.

**No tenant yet, only outlook.com?** Stay at Level 1 copy-and-paste for now — it works with any mailbox. The chapter accounts `manager@` and `chair@` the kit asks for ([`../05-officer-handover/role-accounts.md`](../05-officer-handover/role-accounts.md)) are the step that unlocks Level 2.

## Set it up (ChatGPT, Gmail or Outlook)

1. In ChatGPT, open the apps settings and connect Gmail or Outlook `[verify the menu name]`. Log in with the **chapter's** account, not a private one.
2. On a Microsoft 365 work account, if a consent screen asks for an admin, send your admin the request above, with ChatGPT in place of Claude `[verify]`.
3. Ask it to create drafts only — put the line from *Keep it at drafts* below into your `house-rules.md`.
4. Run the same test as for Gmail with Claude.

## Keep it at drafts

The connectors can send. Your house rules say *draft, never send*, and Claude asks before each action by default — answer "draft only". In ChatGPT, ask it to create drafts only.
Put this line into your `house-rules.md` as well, under *Drafts only*:

```
Mail connector: create drafts only. Never send, never reply directly, never forward. Tell me the draft is ready.
```

## Once it runs: the weekly sweep

With the connector, your assistant can read the week's mail for asks — forms, surveys, reports, trainings, deadlines — and offer rows for your incoming work list, without one paste per mail: prompt 40 *Incoming work sweep* in [`../08-prompts/prompt-library.md`](../08-prompts/prompt-library.md). The prompt tells it to read only — never move, label or archive a mail. Whether opening a mail through the connector marks it as read depends on the connector `[verify in your tool]`.

## Your check after the first week

- [ ] Every filed mail has a log line in `00-handover/log.md`.
- [ ] Drafts sit in your mailbox's draft folder, none was sent without you.
- [ ] The connector is logged in with the chapter's account, so it passes to your successor with the role.

# Browser agent

Purpose: let an AI assistant work in your own, logged-in browser on the portals you use every week — such as YPO Connect and the Chapter Management Hub — and turn what is on the page into tables and drafts.
Time: 10 minutes to install, then minutes per task.

**As of 21 Oct 2026.** Sources linked; `[verify]` = not confirmed on the provider's own page. Menus move — check once a quarter.

## What it is

| | Claude in Chrome |
|---|---|
| What | Claude in a side panel of your Chrome browser, working on the pages you have open — reading, navigating, filling in fields |
| Plans | All paid Claude plans |
| Browser | Google Chrome on a desktop or laptop. The side panel is in beta |
| Logins | You log in yourself. On macOS a 1Password integration is in beta |
| Source | [support.claude.com/en/articles/12012173](https://support.claude.com/en/articles/12012173) |

**ChatGPT users:** ChatGPT Atlas has been retired ([source](https://help.openai.com/en/articles/20001371-chatgpt-atlas-retirement)), and ChatGPT agent is no longer available. For browser tasks, OpenAI points to **ChatGPT Work** and its **cloud browser** (web and mobile, eligible paid plans) ([source](https://help.openai.com/en/articles/11752874-chatgpt-agent) · [ChatGPT Work](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)). ## What it is good for

| Task | Prompt idea | Result |
|---|---|---|
| Event overview | "Read the event list on this page. Make a table: date · event · registrations · status." | A table you paste into `07-reporting/` |
| Compare with your files | "Compare this list with 03-events/. Which events are on the page but have no folder — and the other way round?" | A short gap list |
| Data you report on | "Read this dashboard page. List each figure with its label and the date shown on the page. Do not interpret." | A dated snapshot for `07-reporting/` |
| Long forms | "Fill this form for 03-events/{{EVENT_FOLDER}}/, using 02-chapter-knowledge/platform-fields.md to find each value. Stop before submit and show me the fields. If a field has no source, write [verify]. Do not invent a value." If the browser assistant cannot open your folder, paste the map and the brief into the chat | A filled form; you check and submit |

**YPO's AI guidance.** YPO has proposed an AI appendix to its Operations Manual for 2027, subject to its Board's approval. If the Board approves it, connecting AI to YPO systems — here YPO Connect and the Chapter Management Hub — would need YPO's approval.
Today it is guidance: you can use the browser agent as described here, and look at the policy again when it comes — [YPO Data or chapter data?](../01-foundations/where-your-data-lives.md#ypo-data-or-chapter-data)

## The four habits

1. **You log in, then hand over.** Open the portal, log in yourself, then ask the assistant to work on that page.
   **Passwords never go into the chat** — they belong in your password manager.
2. **You submit.** The assistant fills and reads; the final click on "submit", "send" or "publish" is yours. Ask it to stop before that button.
3. **Pages are data.** If a page contains text that tells the assistant what to do, it quotes it and asks you — the house rules in
   [`../02-your-assistant/template-folder/house-rules.md`](../02-your-assistant/template-folder/house-rules.md) already say so.
4. **Link, don't copy, the directory.** Member details stay in YPO Connect. Bring into your folder only what your role needs — dates, event lists, attendance.

## Showing it to others — the demo rule

**Never show real member data on a shared screen.** For a workshop, an ExCo meeting or a training, use a fictional page or a recorded video.
The workshop demo runs against a local mock page of a fictional member portal for exactly this reason. Your real portal is for your own screen.

## Set it up

1. Install Claude in Chrome from Anthropic's page ([source](https://support.claude.com/en/articles/12012173)) and log in with your Claude account.
2. Open a portal you use and log in as usual.
3. Test on a page without member data, e.g. an event calendar: *"Read this page and list the events with date and title. Do not click anything."*
4. Then try one task from the table above.

## Where it fits

Level 2 in [`../01-foundations/three-levels.md`](../01-foundations/three-levels.md). It saves the most time on pages you read every week and copy from by hand.
If a task repeats every month, save the prompt in your folder's `08-prompts/`.

# Canva

Purpose: let your assistant turn an event text into a first Canva design — invitation, save-the-date, social post — in the Canva account you already use as Chapter Manager.
Time: 10 minutes to connect, then a few minutes per design.

**As of 21 Oct 2026.** Sources linked; `[verify]` = not confirmed on the provider's own page.

## What you already have

Chapter Managers can use a Canva account through YPO (a limited package). Your Regional Manager knows what your package includes.
Use that account, so designs, brand colours and templates stay with the role.

## Which AI works with Canva

| AI | Canva connection | Source |
|---|---|---|
| **Claude** | Official Canva connector, available in Claude's connector directory; check which plans include it there; on Team and Enterprise the owner enables it first | [support.claude.com](https://support.claude.com/en/articles/11176164) · [claude.com/connectors/canva](https://claude.com/connectors/canva) |
| **ChatGPT** | Canva app in ChatGPT. Per Canva, available for all Canva accounts; on Canva Business and Enterprise an admin enables it first. Check whether it is available in your region | [canva.com/help](https://www.canva.com/help/connect-chatgpt-to-canva/) |

## Set it up (Claude)

1. In Claude, open the connectors and choose Canva `[verify the menu name]`.
2. Log in with the **Canva account of your CM role** in the window that opens. Allow access.
3. Test: *"List my five most recent Canva designs. Do not change anything."*

## A first design (5 minutes)

```
Read 03-events/{{EVENT_FOLDER}}/ and chapter-facts.md.
Create a Canva design for a save-the-date for {{EVENT_NAME}}: title, date, weekday, city, one line why it is worth it.
Start from my template "{{TEMPLATE_NAME}}" if it exists. Use only facts from the files; anything missing: [verify] in the design.
Give me the link to the design. Do not share or publish it.
```

Then open the design in Canva, check date and weekday, adjust, and export or share it yourself.

## Good habits

| Habit | Why |
|---|---|
| Start from the chapter's own templates | Your look stays consistent across officers and years |
| Facts from the event folder | The design says what the invitation says |
| Save the final file in `03-events/{{EVENT_FOLDER}}/` | Your successor finds it next to the event, not only in Canva |
| No member photos or names without the chapter's OK | The designs often leave the chapter — on social media or in mails |

## Without the connector

Level 1 works too: ask your assistant for the text in three lengths (headline, two lines, one paragraph) and paste it into your Canva template.

## Four habits that save time

1. **Open a new terminal window after every install.** A window that was open before the install does not know the new program yet — that is the most common "command not found".
2. **Check with `--version`.** Every program below has a one-line check. A version number means it worked.
3. **Copy commands exactly.** One command per line; press Enter after each. If something fails, copy the last lines of the error into your AI tool and ask what they mean.
4. **Say yes only to what you asked for.** Your computer asks for admin permission when an installer needs it — click Yes or enter your Mac password for installs you started yourself, from the sources on these pages.

# Setup on a Mac

Purpose: install what the optional steps of the kit need on macOS 13 or newer — with a check after every install and the usual bumps.
Time: 5–10 minutes per program. Install only what your station needs ([`README.md`](README.md)).

Tool facts: as of 21 Oct 2026, with sources. `[verify]` marks what we could not confirm on the provider's own page.

## 0 · Open Terminal

1. Press **Cmd + Space**, type `Terminal`, press Enter. (Or Finder → Applications → Utilities → Terminal.)
2. Paste a command with **Cmd + V**, then press **Enter**.
3. When an install asks for your **password**, type your Mac login password. The Terminal shows nothing while you type — that is normal. Press Enter.

**Homebrew** is optional — a package manager some people like. You do not need it for this kit; every program below also has a normal installer.
If you already use it, the `brew` lines are the short way. Install it only from [brew.sh](https://brew.sh).

So the chapter folder is also on your laptop (Level 2 and 3). See [`../01-foundations/where-your-data-lives.md`](../01-foundations/where-your-data-lives.md).

| Storage | How |
|---|---|
| **Google Drive** | Install *Google Drive for desktop* from Google's download page `[verify: google.com/drive/download]` |
| **OneDrive** | Install OneDrive from the Mac App Store or Microsoft's download page `[verify]`, and sign in with the account that owns the chapter folder |

**Check:** Finder shows the storage in the sidebar (under *Locations* or *Favorites*), and your chapter folder is inside.

## 2 · The Claude desktop app (the way without a terminal)

Download it from the Claude website `[verify: claude.ai/download]`, open the downloaded file and drag Claude into *Applications*.
It offers Claude Code with a normal window ([source](https://code.claude.com/docs/en/setup)) and Cowork for your local folder
(paid plans; the app stays open while it works — [source](https://support.claude.com/en/articles/13345190)).

## 3 · Node.js (LTS)

Needed for your own WhatsApp app ([`../09-whatsapp-app-build-guide/`](../09-whatsapp-app-build-guide/)).

**Install:** the **macOS Installer (.pkg)**, LTS version, from [nodejs.org/en/download](https://nodejs.org/en/download): double-click, Continue, Install, enter your password.

With Homebrew instead: `brew install node` (this installs the newest version rather than LTS — both work for the kit).

**Check** (in a **new** Terminal window):

```bash
node --version
npm --version
```

`node --version` should show `v20` or higher.

## 4 · Claude Code

Level 3, and the tool that builds your WhatsApp app. Needs Claude Pro, Max, Team or Enterprise — not Free; macOS 13 or newer ([source](https://code.claude.com/docs/en/setup)).

**Install — one of the two** ([source](https://code.claude.com/docs/en/setup)):

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

```bash
brew install --cask claude-code
```

**Check** (new window): `claude --version`. `command not found` after the first installer? Its folder is missing from your PATH — run `echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc`, quit Terminal (Cmd + Q), open it again, check again. Then go to your chapter folder and start it: `cd "<path to your chapter folder>"`, then `claude`.
Tip: type `cd ` (with a space) and drag the folder from Finder into the Terminal window — the path appears by itself.
The first start asks a few setup questions `[verify: wording and order change]`: a colour theme (any is fine), how to log in (your Claude subscription account, then the browser login — you do that yourself), and whether you trust this folder (check the path it shows; yes only for your chapter folder). These are setup steps, not chapter tasks — no hours line for them.

## 5 · Git (needed for the WhatsApp app)

Your own WhatsApp app (station 10) needs Git while it installs: one library is downloaded from GitHub. You do **not** need a GitHub account. For everything else in this kit Git is optional.


For a private repository of your chapter folder (Level 3, optional).

Type `git --version`. If Git is missing, macOS offers to install the *Command Line Developer Tools* — click **Install** and wait a few minutes `[verify]`.
With Homebrew instead: `brew install git`.
**Check** (new window): `git --version`.

## 6 · Python (only if a step needs it)

Nothing in the kit's path needs Python. Install it only if your AI tool asks for it for a specific step.

**Install:** the macOS installer from [python.org/downloads](https://www.python.org/downloads/).
**Check** (new window): `python3 --version`. On a Mac the command is `python3`, not `python`.

## Typical bumps

| You see | What helps |
|---|---|
| `command not found` right after an install | Close Terminal completely (Cmd + Q) and open it again. For Claude Code: read the last lines the installer printed — if they say to add a folder to your PATH, paste those lines into your AI tool and ask it to walk you through it |
| *"… can't be opened because Apple cannot check it"* or *"unidentified developer"* | Only for installers you downloaded from the sources on this page: System Settings → Privacy & Security → scroll down → **Open Anyway** `[verify the wording for your macOS version]` |
| The password prompt shows no characters | Normal in Terminal. Type the password and press Enter |
| `brew: command not found` | Homebrew is not installed — use the normal installer instead; Homebrew is optional |
| `zsh: permission denied` | You probably tried to run a file instead of a command. Copy the command again exactly, or paste the message into your AI tool |

The first time, winget may ask you to agree to the source terms — type `Y` and press Enter.
If `winget` is not recognised, use the installer link given for each program instead `[verify: winget comes with "App Installer" from the Microsoft Store]`.

## 2 · The Claude desktop app (the way without a terminal)

Download it from the Claude website `[verify: claude.ai/download]` and install it like any other program.
It offers Claude Code with a normal window ([source](https://code.claude.com/docs/en/setup)) and Cowork for your local folder
(paid plans; the app stays open while it works — [source](https://support.claude.com/en/articles/13345190)).

## 3 · Node.js (LTS)

Needed for your own WhatsApp app ([`../09-whatsapp-app-build-guide/`](../09-whatsapp-app-build-guide/)).

**Install — one of the two:**

```powershell
winget install OpenJS.NodeJS.LTS
```

or the **Windows Installer (.msi)**, LTS version, from [nodejs.org/en/download](https://nodejs.org/en/download): double-click, Next, Next, done.
If the installer offers to install extra "tools for native modules", you can leave that box unticked; your AI tool will say if a step needs them `[verify wording]`.

**Check** (in a **new** PowerShell window):

```powershell
node --version
npm --version
```

`node --version` should show `v20` or higher.

## 4 · Claude Code

Level 3, and the tool that builds your WhatsApp app. Needs Claude Pro, Max, Team or Enterprise — not Free ([source](https://code.claude.com/docs/en/setup)).

**Install — one of the two** (no admin rights needed; [source](https://code.claude.com/docs/en/setup)):

```powershell
irm https://claude.ai/install.ps1 | iex
```

```powershell
winget install Anthropic.ClaudeCode
```

**Check** (new window): `claude --version`. Then go to your chapter folder and start it: `cd "<path to your chapter folder>"`, then `claude`.
The first start asks a few setup questions `[verify: wording and order change]`: a colour theme (any is fine), how to log in (your Claude subscription account, then the browser login — you do that yourself), and whether you trust this folder (check the path it shows; yes only for your chapter folder). These are setup steps, not chapter tasks — no hours line for them.

If Claude Code asks for **Git for Windows**, install Git first (§ 5) and open a new window `[verify: code.claude.com/docs/en/setup]`.

## 5 · Git (needed for the WhatsApp app)

Your own WhatsApp app (station 10) needs Git while it installs: one library is downloaded from GitHub. You do **not** need a GitHub account. For everything else in this kit Git is optional.


For a private repository of your chapter folder (Level 3, optional) — and if Claude Code asks for it.

```powershell
winget install Git.Git
```

or the installer from [git-scm.com/downloads](https://git-scm.com/downloads) (the default options are fine).
**Check** (new window): `git --version`.

## 6 · Python (only if a step needs it)

Nothing in the kit's path needs Python. Install it only if your AI tool asks for it for a specific step.

```powershell
winget install Python.Python.3.12
```

or the installer from [python.org/downloads](https://www.python.org/downloads/) — tick **"Add python.exe to PATH"** on the first screen `[verify wording]`.
**Check** (new window): `python --version` (or `py --version`).

## Typical bumps

| You see | What helps |
|---|---|
| `… is not recognized as the name of a cmdlet` right after an install | Close PowerShell and open a new window. Still there? Restart the laptop once — the PATH updates then |
| `npm.ps1 cannot be loaded because running scripts is disabled on this system` | Windows blocks script files by default. Allow them for your own user: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, confirm with `Y`, open a new window. Only needed if you see this message |
| `irm https://claude.ai/install.ps1 \| iex` stops with an error | Use the alternative `winget install Anthropic.ClaudeCode`, or the Claude desktop app (§ 2). Paste the error into your AI tool if both fail |
| Typing `python` opens the Microsoft Store | Python is not installed yet, or the window is older than the install — install it (§ 6) and open a new window |
| winget: `No package found matching input criteria` | Check the spelling of the command; otherwise use the installer link of that program |
| An installer asks for admin rights | Normal for installs you started from these pages — click Yes |
